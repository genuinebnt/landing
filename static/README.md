# static

Files copied verbatim into `sites/` at build time, preserving structure. Use
this for anything that is not generated from an artboard.

    static/cv/genuine-basil-nt-cv.pdf  ->  https://cv.genuinebasil.dev/genuine-basil-nt-cv.pdf

The CV page's download button points at exactly that path. Until the PDF is
dropped here the button 404s — the link is live, the file is not.
